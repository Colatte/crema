Crema 1.6.1

A small maintenance release. Nothing about how the app works or is set up changed.

Changed

  • The About tab signs in words. "made with coffee by Colatte" replaces the coffee-cup glyph, so the line reads the same to VoiceOver as it does on screen. With it gone, no string in the app carries an emoji, and the string catalog now refuses one on either language.

Requirements: macOS 14 (Sonoma) or later · Apple Silicon or Intel.

Crema isn't notarized by Apple, so a fresh install needs one extra step on first launch — see First launch in the README. Updating from 1.2.0 or later happens on its own.
